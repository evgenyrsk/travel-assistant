# T-Bank Hotels Browser MCP

Локальный MCP-сервер для сценариев раздела «Отели» Т-Банка. Инструмент не
использует внутренние HTTP endpoint-ы сайта: он управляет только браузером через
установленный `agent-browser`.

## Что поддерживается

- публичная главная страница, подборки городов и карточки отелей;
- поиск направления с отображением подсказок и параметризованная выдача по
  городу, датам и числу гостей;
- пошаговое управление датами, гостями, фильтрами, картой, пагинацией, фото,
  отзывами и удобствами через `snapshot` + `click`;
- предпросмотр номера и тарифа с датами, условиями отмены, итоговой суммой и
  доступными способами оплаты до финального действия;
- ручной вход в Интернет-банк в видимом браузере;
- импорт существующей авторизованной cookie-сессии из локального файла;
- просмотр разделов «Избранное», «Заказы» и карточки существующего заказа
  после авторизации;
- просмотр статуса брони, условий отмены, способов оплаты, кэшбэка и доступных
  документов без выполнения действия.

### Полнота сценариев

`tbank_hotels_fill_destination` покрывает поиск по названию отеля, городу,
стране и локации из подсказок. Даты, гости, фильтры, сортировка, карта,
пагинация, фото, отзывы, номера и тарифы управляются пошагово через
`snapshot` + `click`. Для авторизованного пользователя доступны «Избранное»,
список заказов и карточка заказа.

Для действий с внешним эффектом используйте два шага:

1. Вызовите `tbank_hotels_arm_user_action` с ref кнопки из последнего
   snapshot. Сервер вернёт точное название действия и одноразовое
   подтверждение.
2. Покажите пользователю это действие, включая цену и условия на странице, и
   получите явное подтверждение непосредственно перед выполнением. Только
   после этого вызовите `tbank_hotels_execute_armed_action`.

Этот протокол применим к созданию брони, оплате, подтверждению, отмене,
изменению «Избранного» и загрузке документов. Подтверждение действует пять
минут и аннулируется, если экран изменился.

Финальное создание бронирования, оплата, покупка, подтверждение, отмена,
изменение «Избранного» и скачивание документов требуют одноразового явного
подтверждения пользователя. Без него MCP останавливается перед действием.
Платёжные данные, коды подтверждения и документы не передавайте через MCP:
пользователь вводит их только в видимом окне T‑Bank.

## Запуск

```bash
cd tools/tbank-hotels-mcp
npm start
```

Добавьте MCP-клиенту stdio-конфигурацию:

```json
{
  "command": "node",
  "args": ["/absolute/path/to/travel-assistant/tools/tbank-hotels-mcp/src/server.mjs"]
}
```

Для ручного входа вызовите `tbank_hotels_start_login` и завершите его в открытом
окне браузера. Не передавайте в чат или аргументы MCP пароль, одноразовый код,
данные карты или cookie.

Для импорта готовой сессии сохраните экспорт cookie в файл. В DevTools откройте
`Network`, выберите любой авторизованный запрос, нажмите правой кнопкой мыши,
выберите `Copy` → `Copy as cURL`, вставьте результат в локальный файл и передайте
только абсолютный путь к нему в `tbank_hotels_import_auth_cookies`. Содержимое
этого файла MCP не выводит.
