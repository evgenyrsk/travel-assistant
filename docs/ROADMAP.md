# Roadmap

Этот документ описывает верхнеуровневый product roadmap. Детальный порядок implementation-задач и milestones ведется отдельно в `docs/development/roadmap.md` и `docs/development/milestones.md`.

## Phase 1: Discovery

- Define the first platform and primary user flow.
- Pick implementation stack.
- Draft data model for trips, travelers, places, and itinerary items.
- Identify must-have external APIs.

## Phase 2: Prototype

- Build trip creation flow.
- Generate a basic itinerary from user preferences.
- Save and edit itinerary items.
- Add basic tests around planning logic.

## Phase 3: Assistant Experience

- Add conversational planning and refinement.
- Add memory for travel preferences.
- Support exports and sharing.
- Add integration tests for provider adapters.
