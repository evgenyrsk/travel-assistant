# Codex Prompt Templates

This directory contains reusable Codex prompt templates and prompt-writing guidance.

Canonical repository governance lives in `../../AGENTS.md`. Development and quality rules live in `../development/`, and backend layering rules live in `../architecture/backend-layering-rules.md`.

## Templates

- [Codex task template](codex-task-template.md) - use for implementation, documentation, and maintenance tasks.
- [Codex review template](codex-review-template.md) - use for read-only review tasks.
- [Legacy task template](task-template.md) - compatibility redirect for old links; use the Codex task template for new tasks.
- [Legacy review template](review-template.md) - compatibility redirect for old links; use the Codex review template for new reviews.
- [Prompt companion](codex-rules.md) - concise guidance for avoiding duplication of `AGENTS.md`.

Templates should link to governance documents instead of copying long rule blocks.
